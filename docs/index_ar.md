# وثائق HFF Survey Plugin

مرحباً بكم في الوثائق الرسمية لبرنامج HFF (مؤسسة هونور فروست) المساعد لـ QGIS.

## عن HFF

HFF هو برنامج مساعد مفتوح المصدر لإدارة بيانات المسح الأثري داخل QGIS. يوفر أدوات متخصصة لإدارة المسوحات الأثرية تحت الماء والبرية.
