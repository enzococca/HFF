# تكامل EAMENA

يشرح هذا الدليل كيفية استخدام ميزات تكامل بيانات EAMENA (علم الآثار المهددة في الشرق الأوسط وشمال أفريقيا) في HFF Survey.

## ما هو EAMENA؟

EAMENA هو مشروع دولي يوثق المواقع الأثرية المهددة في الشرق الأوسط وشمال أفريقيا. يتضمن HFF أدوات لـ:

- تصدير البيانات بتنسيق متوافق مع EAMENA
- إنشاء صحائف الأماكن التراثية EAMENA
- استيراد بيانات EAMENA
- المزامنة مع قاعدة بيانات EAMENA

---

## فتح أدوات EAMENA

1. انقر على **قائمة HFF > أدوات EAMENA**
2. أو انقر على أيقونة **EAMENA** ![EAMENA](icons/eamena.png) في شريط الأدوات

---

## هيكل بيانات EAMENA

### حقول الأماكن التراثية

| حقل EAMENA | المكافئ في HFF |
|------------|----------------|
| EAMENA_ID | يُنشأ تلقائياً |
| الاسم | name_site |
| البلد | (يُستنتج من الموقع) |
| الموقع | location_ |
| نوع الموقع | definition |
| الفترة الثقافية | dating |
| الحالة العامة | condition_state |
| نوع التهديد | disturbance |
| تاريخ التقييم | date_start |

### المرجع الشبكي

يستخدم EAMENA نظام شبكي محدد:

| الحقل | الوصف |
|-------|-------|
| **خط العرض** | درجات عشرية |
| **خط الطول** | درجات عشرية |
| **الهندسة** | نقطة، مضلع، خط |
| **مربع الشبكة** | المرجع الشبكي EAMENA |

---

## التصدير إلى تنسيق EAMENA

### تصدير موقع واحد

1. انتقل إلى سجل الموقع
2. انقر **تصدير > تنسيق EAMENA**
3. راجع الحقول المربوطة
4. انقر **تصدير**
5. احفظ ملف Excel

### التصدير المجمع

1. فلتر المواقع للتصدير
2. انقر **تصدير الكل > تنسيق EAMENA**
3. اضبط خيارات التصدير:
   - تضمين الهندسة
   - تضمين الصور
   - تضمين تقييمات الحالة
4. انقر **تصدير**

### خيارات التصدير

| الخيار | الوصف |
|--------|-------|
| **تضمين الهندسة** | تصدير البيانات المكانية |
| **إنشاء معرفات EAMENA** | إنشاء المعرفات تلقائياً |
| **تضمين الصور** | ربط ملفات الوسائط |
| **تضمين المراجع** | تصدير الببليوغرافيا |

### صحيفة التهديدات

## مولد البيانات (بمساعدة الذكاء الاصطناعي)

يتضمن HFF مولد بيانات EAMENA بالذكاء الاصطناعي:

### الإعداد

1. افتح **أدوات EAMENA > مولد البيانات**
2. أدخل مفتاح OpenAI API الخاص بك
3. حدد مجلد الإخراج

### إنشاء البيانات

1. أدخل وصف الموقع أو المعلمات
2. حدد عدد السجلات
3. انقر **إنشاء**
4. راجع البيانات المُنشأة
5. عدّل حسب الحاجة
6. صدّر إلى Excel

### حالات الاستخدام

- مجموعات بيانات التدريب
- أمثلة القوالب
- مساعدة إدخال البيانات المجمعة

---

## استيراد بيانات EAMENA

### خطوات الاستيراد

1. انقر **استيراد > Excel EAMENA**
2. حدد ملف Excel
3. اربط الأعمدة بحقول HFF
4. راجع معاينة الاستيراد
5. انقر **استيراد**

### ربط الحقول

| حقل EAMENA | يُربط إلى |
|------------|-----------|
| اسم المورد | name_site |
| المرجع الشبكي | geometry_collection |
| نوع الموقع | definition |
| الفترة الثقافية | dating |
| الحالة | condition_state |

### خيارات الاستيراد

| الخيار | الوصف |
|--------|-------|
| **إنشاء مواقع جديدة** | إضافة سجلات جديدة |
| **تحديث الموجودة** | مطابقة وتحديث |
| **تجاوز المكررات** | تجاهل الموجودة |
| **استيراد الوسائط** | تنزيل الملفات المرتبطة |

## أفضل الممارسات

### جودة البيانات

- تحقق من دقة الإحداثيات
- استخدم مفردات EAMENA المحكومة
- أضف ملاحظات عدم اليقين
- وثّق مصادر البيانات

### سير العمل

1. أكمل سجلات HFF أولاً
2. شغّل فحوصات التحقق
3. صدّر إلى تنسيق EAMENA
4. راجع البيانات المُصدَّرة
5. أرسل إلى قاعدة بيانات EAMENA

### المزامنة

- صدّر بانتظام للنسخ الاحتياطي
- حافظ على اتساق معرفات EAMENA
- وثّق أي تعديلات
- تتبع سجل الإرسال

---

## استكشاف الأخطاء وإصلاحها

### أخطاء التصدير

- تحقق من اكتمال الحقول المطلوبة
- تحقق من تنسيق الإحداثيات
- تأكد من تطابق مصطلحات المفردات

### مشاكل الاستيراد

- تحقق من تطابق تنسيق Excel مع القالب
- تحقق من الأحرف الخاصة
- راجع ربط الحقول

### تعارض المعرفات

- استخدم معرفات EAMENA فريدة
- لا تعيد استخدام المعرفات المحذوفة
- وثّق تعيينات المعرفات
