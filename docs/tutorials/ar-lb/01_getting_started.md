## المقدمة

إضافة **HFF (مؤسسة هونور فروست) للمسح** هي أداة مفتوحة المصدر شاملة لإدارة بيانات المسوحات الأثرية ضمن برنامج QGIS. تم تطويرها بدعم من مؤسسة هونور فروست، وتوفر أدوات متخصصة لإدارة المسوحات الأثرية تحت الماء والبرية.

<!-- VIDEO: Introduction to HFF Plugin -->
> **فيديو تعليمي**: مقدمة إلى إضافة HFF للمسح

### الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| **إدارة المواقع** | توثيق وإدارة المواقع الأثرية |
| **تتبع سجلات الغوص** | تسجيل عمليات المسح تحت الماء |
| **فهرسة المراسي** | توثيق اكتشافات المراسي مع قياسات تفصيلية |
| **توثيق حطام السفن** | تسجيل مواقع حطام السفن وميزاتها |
| **تسجيل القطع الأثرية** | فهرسة القطع الأثرية الفردية مع بيانات وصفية كاملة |
| **تحليل الفخار** | تصنيف وجرد الفخار التفصيلي |
| **تكامل EAMENA** | توثيق مواقع التراث وفق معايير EAMENA |
| **تقارير PDF** | إنشاء تقارير PDF احترافية |
| **إدارة الصور** | تصنيف وتنظيم ملفات الوسائط |
| **تكامل نظم المعلومات الجغرافية** | إمكانيات التحليل المكاني الكامل |
| **دعم متعدد اللغات** | واجهات بالإنجليزية والعربية اللبنانية |

## متطلبات النظام

### المتطلبات الدنيا

| المكون | المتطلب |
|--------|---------|
| **QGIS** | الإصدار 3.22 أو أعلى |
| **Python** | الإصدار 3.9 أو أعلى |
| **نظام التشغيل** | Windows 10+، macOS 10.14+، Linux |
| **ذاكرة الوصول العشوائي** | 4 جيجابايت كحد أدنى |
| **مساحة القرص** | 500 ميجابايت للإضافة والتبعيات |

### خيارات قاعدة البيانات

| قاعدة البيانات | الأفضل لـ | ملاحظات |
|----------------|-----------|---------|
| **SQLite/SpatiaLite** | مستخدم واحد، مشاريع محمولة | لا حاجة لخادم، قائمة على الملفات |
| **PostgreSQL/PostGIS** | الفرق، المشاريع الكبيرة | يتطلب إعداد خادم |

### الإعداد الموصى به

| المكون | التوصية |
|--------|---------|
| **QGIS** | أحدث إصدار طويل الدعم (LTR) |
| **ذاكرة الوصول العشوائي** | 8 جيجابايت أو أكثر |
| **الشاشة** | دقة 1920x1080 أو أعلى |
| **الإنترنت** | مطلوب لبعض الميزات (التخزين البعيد، الترميز الجغرافي) |

### الطريقة 2: التثبيت اليدوي

لإصدارات التطوير أو التثبيت بدون إنترنت:

#### الخطوة 1: التحميل
حمّل الإضافة من GitHub:
```
https://github.com/enzococca/HFF
```

#### الخطوة 2: الاستخراج
1. حمّل ملف ZIP
2. استخرجه إلى مجلد إضافات QGIS:

| نظام التشغيل | موقع مجلد الإضافات |
|--------------|-------------------|
| **Windows** | `C:\Users\USERNAME\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\` |
| **macOS** | `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins/` |
| **Linux** | `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/` |

#### الخطوة 3: تفعيل الإضافة
1. أعد تشغيل QGIS
2. اذهب إلى **الإضافات** ← **إدارة وتثبيت الإضافات...**
3. انقر على تبويب **المُثبّتة**
4. ضع علامة بجانب "HFF Survey"

## إعداد قاعدة البيانات

### إنشاء قاعدة بيانات جديدة

#### قاعدة بيانات SQLite (موصى بها للمبتدئين)

1. افتح **الإعدادات** من شريط الأدوات أو القائمة
2. اختر **SQLite** كنوع قاعدة البيانات
3. انقر **إنشاء قاعدة بيانات جديدة**
4. اختر الموقع واسم الملف
5. انقر **حفظ**

<!-- IMAGE: SQLite setup -->
![إعداد SQLite](images/01_getting_started/10_sqlite_setup.png)
*الشكل 10: إنشاء قاعدة بيانات SQLite جديدة*

#### قاعدة بيانات PostgreSQL

1. افتح **الإعدادات**
2. اختر **PostgreSQL** كنوع قاعدة البيانات
3. أدخل معلمات الاتصال:

| الحقل | الوصف | مثال |
|-------|-------|------|
| **المضيف** | عنوان الخادم | localhost |
| **المنفذ** | منفذ الخادم | 5432 |
| **قاعدة البيانات** | اسم قاعدة البيانات | hff_survey |
| **اسم المستخدم** | اسم المستخدم الخاص بك | hff_user |
| **كلمة المرور** | كلمة المرور الخاصة بك | ******** |

4. انقر **اختبار الاتصال**
5. انقر **إنشاء الجداول** إذا كانت قاعدة بيانات جديدة
6. انقر **حفظ**

<!-- IMAGE: PostgreSQL setup -->
![إعداد PostgreSQL](images/01_getting_started/11_postgresql_setup.png)
*الشكل 11: إعدادات اتصال PostgreSQL*

## حل المشاكل

### الإضافة لا تُحمّل

**الأعراض**: HFF لا تظهر في قائمة الإضافات أو لا تُفعّل

**الحلول**:
1. تحقق من إصدار QGIS (يتطلب 3.22+)
2. تحقق من إصدار Python (يتطلب 3.9+)
3. أعد تثبيت الإضافة
4. تحقق من سجل أخطاء QGIS: **عرض** ← **اللوحات** ← **رسائل السجل**

### فشل اتصال قاعدة البيانات

**الأعراض**: خطأ "فشل الاتصال"

**الحلول**:
1. تحقق من معلمات الاتصال
2. تحقق من تشغيل خادم قاعدة البيانات (PostgreSQL)
3. تحقق من أذونات الملف (SQLite)
4. اختبر الاتصال من سطر الأوامر:
   ```bash
   psql -h localhost -U username -d database
   ```

### التبعيات لا تُثبّت

**الأعراض**: أخطاء استيراد، وحدات مفقودة

**الحلول**:
1. شغّل مثبّت التبعيات يدوياً:
   ```bash
   python scripts/modules_installer.py
   ```
2. تحقق من تثبيت pip:
   ```bash
   python -m pip --version
   ```
3. ثبّت الحزم يدوياً:
   ```bash
   pip install SQLAlchemy GeoAlchemy2 reportlab xlsxwriter pandas
   ```

### النماذج لا تُعرض بشكل صحيح

**الأعراض**: مشاكل في التخطيط، أزرار مفقودة

**الحلول**:
1. تحقق من دقة الشاشة (1920x1080 موصى بها)
2. أعد ضبط تخطيط النافذة: **عرض** ← **اللوحات** ← **إعادة الضبط إلى الافتراضي**
3. تحقق من توافق إصدار Qt/PyQt5

### البيانات لا تُحفظ

**الأعراض**: التغييرات تُفقد، أخطاء حفظ

**الحلول**:
1. تحقق من اتصال قاعدة البيانات
2. تحقق من ملء الحقول المطلوبة
