## حقول النموذج - مرجع كامل

### علامة التبويب 1: التعريف

#### معرف المرساة (مطلوب)

| الخاصية | القيمة |
|---------|--------|
| **اسم الحقل** | `anchors_id` |
| **النوع** | نص (سلسلة) |
| **مطلوب** | نعم |
| **فريد** | نعم |
| **الحد الأقصى للطول** | 50 حرفاً |

**الوصف:** معرف فريد للمرساة.

**أمثلة التنسيق:**
| التنسيق | مثال | الوصف |
|---------|-------|-------|
| تسلسلي | `ANC-001` | تسلسل مرقم بسيط |
| حسب الموقع | `TYR-ANC-001` | رمز الموقع + رقم المرساة |
| حسب النوع | `SA-001` | مرساة حجرية + رقم |
| حسب السياق | `SW01-ANC-001` | حطام السفينة + رقم المرساة |

**قواعد التحقق:**
- لا يمكن أن يكون فارغاً
- يجب أن يكون فريداً في قاعدة البيانات
- الأحرف المسموح بها: حروف، أرقام، شرطة (-)، شرطة سفلية (_)

**الأخطاء الشائعة:**
| الخطأ | السبب | الحل |
|-------|-------|------|
| "المعرف موجود بالفعل" | معرف مكرر | استخدم معرفاً فريداً |
| "المعرف مطلوب" | حقل فارغ | أدخل معرفاً صالحاً |

---

|---------|--------|

| **النوع** | قائمة منسدلة (من جدول المواقع) |
| **مطلوب** | موصى به |

**الوصف:** الموقع الأثري المرتبط.

**ملاحظة:** أنشئ الموقع أولاً عبر نموذج الموقع إذا لم يكن في القائمة.

**الوصف:** منطقة محددة داخل الموقع.

#### الوزن

| الخاصية | القيمة |
|---------|--------|
| **اسم الحقل** | `weight` |
| **النوع** | نص |
| **الوحدة** | كيلوجرام |

**أمثلة التنسيق:**
| الإدخال | الوصف |
|---------|-------|

3. **التقدير** - بناءً على مراسي مشابهة

حفريات دقيقة متفرقة. متوافق مع تكوينات الحجر الجيري

### علامة التبويب 7: المراجع

| العمود | الوصف |
|--------|-------|
| المؤلف | اسم/أسماء المؤلف |
| السنة | سنة النشر |
| العنوان | عنوان المنشور |
| المرجع | الاستشهاد الكامل |

**إضافة المراجع:**
1. انقر على زر "إضافة"
2. أدخل تفاصيل الاستشهاد
3. انقر "حفظ"

---

#### موقع التخزين

| الخاصية | القيمة |
|---------|--------|
| **اسم الحقل** | `storage_` |
| **النوع** | نص |

**الوصف:** موقع التخزين الحالي إذا تم استعادتها.

**أمثلة:**
- `المتحف الوطني، القاعة 3، الرف B12`
- `مخزن الجامعة، الصندوق 45`
- `في الموقع (لم تُستعاد)`
- `مختبر الترميم، الحوض 3`

## دليل القياسات

### نقاط قياس المرساة المعيارية

```
                    TW (العرض العلوي)
                 ┌──────────────┐
                 │   ○ TD/RD/LD │  ← الثقب العلوي
              LL │      (ثقب)   │ RL
    (الطول الأيسر)│              │(الطول الأيمن)
                 │              │
                 │      ML      │  (الطول الأقصى)
                 │   (أقصى طول) │
                 │              │
                 │   ○ BD/BDE   │  ← الثقب السفلي (إذا وجد)
                 └──────────────┘
                    BW (العرض السفلي)

    ←── MW (العرض الأقصى) ──→

    السماكة: TT (علوية)، BT (سفلية)
    تُقاس عمودياً على الوجه
```

### أفضل ممارسات القياس

1. **استخدم نقاط مرجعية متسقة**
   - الأعلى = الطرف الأضيق (طرف ثقب الحبل)
   - الأسفل = الطرف الأعرض (القاعدة)

2. **قس الأبعاد القصوى**
   - الطول: أطول نقطة
   - العرض: أعرض نقطة
   - السماكة: أثخن نقطة

3. **وثّق طريقة القياس**
   - قياس مباشر (فرجار، شريط قياس)
   - فوتوغرامتري
   - تقديري

4. **سجّل بالسنتيمتر**
   - استخدم الكسور العشرية للدقة (مثال: 45.5 سم)
   - قرّب لأقرب 0.5 سم

5. **قياسات الثقوب**
   - قس القطر من كلا الفتحتين
   - لاحظ إذا كان الثقب مدبباً
   - قس عمق الثقب

## العمل مع السجلات

### إنشاء سجل مرساة جديد

1. انقر **سجل جديد** ![جديد](icons/newrec.png)
2. أدخل **معرف المرساة** (مطلوب)
3. اختر **الموقع** و**المنطقة**
4. اختر **نوع المرساة** و**الشكل**
5. أدخل جميع القياسات
6. صف الحالة
7. أضف الصور
8. انقر **حفظ** ![حفظ](icons/b_save.png)

### الربط بسجل الغوص

1. افتح سجل المرساة
2. أدخل رقم **معرف سجل الغوص**
3. يُنشئ هذا رابطاً لسجل الغوص
4. احفظ السجل

### البحث عن المراسي

**حسب النوع:**
1. انقر **بحث جديد**
2. اختر نوع المرساة: `مرساة حجرية`
3. انقر **بحث**

**حسب القياسات:**
1. انقر **بحث جديد**
2. أدخل الوزن: `>40` (أكثر من 40 كجم)
3. انقر **بحث**

**حسب الموقع:**
1. انقر **بحث جديد**
2. اختر الموقع من القائمة المنسدلة
3. انقر **بحث**

## التصور ثلاثي الأبعاد

### تحميل النماذج ثلاثية الأبعاد

1. انقر زر **عارض 3D** ![3D](icons/toolbox.png)
2. انقر **تحميل نموذج**
3. اختر ملفك ثلاثي الأبعاد:
   - `.obj` - Wavefront OBJ
   - `.ply` - Stanford PLY
   - `.stl` - تنسيق STL
4. يظهر النموذج في العارض

### عناصر التحكم في العارض ثلاثي الأبعاد

| الإجراء | التحكم |
|---------|--------|
| تدوير | نقر + سحب |
| تكبير | عجلة التمرير |
| تحريك | نقر يمين + سحب |
| إعادة ضبط | نقر مزدوج |

### إنشاء النماذج ثلاثية الأبعاد

**طريقة الفوتوغرامتري:**
1. التقط 50-100 صورة متداخلة
2. عالج ببرنامج فوتوغرامتري
3. صدّر بصيغة OBJ أو PLY
4. استورد إلى HFF

**البرامج الموصى بها:**
- Agisoft Metashape
- Reality Capture
- Meshroom (مجاني)
- COLMAP (مجاني)

## سير عمل الترميم

### تسجيل حالة الترميم

1. انتقل إلى سجل المرساة
2. اذهب إلى علامة تبويب الترميم
3. حدّث **حالة الترميم**
4. سجّل **تاريخ المعالجة**
5. أدخل اسم **المرمم**
6. وثّق المعالجات المطبقة
7. احفظ السجل

### قيم حالة الترميم

| الحالة | الوصف |
|--------|-------|
| غير مطلوب | مستقرة، لا تحتاج معالجة |
| معلق | في انتظار المعالجة |
| قيد التنفيذ | يُعالج حالياً |
| مكتمل | انتهت المعالجة |
| مستمر | يتطلب رعاية دورية |

### الربط بنموذج الترميم

لسجلات الترميم التفصيلية:
1. افتح **HFF > نموذج ترميم المرساة**
2. أنشئ سجل ترميم جديد
3. اربط بالمرساة عبر معرف المرساة
4. سجّل ملاحظات معالجة تفصيلية
5. تتبع العينات والتحاليل

## الأخطاء الشائعة والحلول

### خطأ: "معرف المرساة موجود بالفعل"

| السبب | الحل |
|-------|------|
| معرف مكرر أُدخل | استخدم معرفاً فريداً |
| السجل موجود بالفعل | ابحث عن السجل الموجود أولاً |

### خطأ: "قيمة قياس غير صالحة"

| السبب | الحل |
|-------|------|
| نص في حقل رقمي | أدخل أرقاماً فقط |
| قيمة سالبة | استخدم قيماً موجبة |
| كسور عشرية كثيرة جداً | قرّب لكسر عشري واحد |

### خطأ: "لا يمكن حفظ السجل"

| السبب | الحل |
|-------|------|
| حقل مطلوب فارغ | املأ معرف المرساة |
| قاعدة البيانات مقفلة | انتظر وأعد المحاولة |
| فُقد الاتصال | تحقق من اتصال قاعدة البيانات |

### النموذج ثلاثي الأبعاد لا يُحمّل

| السبب | الحل |
|-------|------|
| تنسيق غير مدعوم | حوّل إلى OBJ/PLY/STL |
| الملف كبير جداً | قلّل تعقيد الشبكة |
| ملف تالف | أعد التصدير من المصدر |

### الصور لا تظهر

| السبب | الحل |
|-------|------|
| مسار خاطئ | تحقق من إعدادات مسار الوسائط |
| الملفات نُقلت | أعد ربط الصور |
| تنسيق غير مدعوم | حوّل إلى JPEG/PNG |

## أفضل الممارسات

### التوثيق

1. **صوّر قبل القياس**
   - وثّق الحالة الأصلية
   - ضمّن مقياساً في الصور
   - التقط زوايا متعددة

2. **قس بشكل منهجي**
   - اتبع نقاط القياس المعيارية
   - سجّل جميع الأبعاد المتاحة
   - دوّن طريقة القياس

3. **صف بشمولية**
   - ضمّن جميع المعالم المرئية
   - دوّن الضرر والحالة
   - وثّق السياق

### جودة البيانات

1. **استخدم مصطلحات متسقة**
   - اتبع مفردات المشروع
   - استخدم قيم القوائم المنسدلة عند توفرها
   - تجنب الاختصارات في الأوصاف

2. **سجّل عدم اليقين**
   - استخدم "حوالي" للتقديرات
   - دوّن صعوبات القياس
   - وثّق الافتراضات

3. **أنشئ مراجع متبادلة**
   - اربط بسجلات الغوص
   - أشر إلى المراسي ذات الصلة
   - اربط بحطام السفينة إن وُجد

### إدارة الوسائط

1. **سمِّ الملفات بشكل منهجي**
   - `ANC-001_overview.jpg`
   - `ANC-001_detail_hole.jpg`
   - `ANC-001_inscription.jpg`

2. **ضمّن البيانات الوصفية**
   - تاريخ الالتقاط
   - المصور
   - الكاميرا/الإعدادات

3. **ضع الوسوم المناسبة**
   - زاوية العرض
   - المعلم المُظهر
   - حالة الترميم
