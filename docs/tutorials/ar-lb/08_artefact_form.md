### علامة التبويب 1: التعريف

#### معرف القطعة الأثرية (مطلوب)

| الخاصية | القيمة |
|---------|--------|
| **اسم الحقل** | `artefact_id` |
| **النوع** | نص (سلسلة) |
| **مطلوب** | نعم |
| **فريد** | نعم |
| **الحد الأقصى للطول** | 50 حرفاً |

**الوصف:** معرف فريد للقطعة الأثرية.

**أمثلة التنسيق:**
| التنسيق | مثال | الوصف |
|---------|-------|-------|
| تسلسلي | `ART-001` | تسلسل مرقم بسيط |
| حسب الموقع | `TYR-ART-001` | رمز الموقع + رقم |
| حسب المادة | `BR-001` | برونز + رقم |
| حسب السياق | `SW01-ART-001` | حطام السفينة + رقم |

**قواعد التحقق:**
- لا يمكن أن يكون فارغاً
- يجب أن يكون فريداً في قاعدة البيانات
- الأحرف المسموح بها: حروف، أرقام، شرطة (-)، شرطة سفلية (_)

### علامة التبويب 3: القياسات

#### الأبعاد (بالسنتيمتر/الميليمتر)

| الحقل | قاعدة البيانات | الوحدة | الوصف |
|-------|---------------|--------|-------|
| **L min** | `lmin` | سم | الطول الأدنى |
| **L max** | `lmax` | سم | الطول الأقصى |
| **W min** | `wmin` | سم | العرض الأدنى |
| **W max** | `wmax` | سم | العرض الأقصى |
| **T min** | `tmin` | سم | السماكة الدنيا |
| **T max** | `tmax` | سم | السماكة القصوى |

**قواعد القياس:**
1. استخدم السنتيمتر للأجسام >5 سم
2. استخدم الميليمتر للأجسام الصغيرة (دوّن في الوصف)
3. سجّل كلا من الأدنى والأقصى للأجسام غير المنتظمة
4. للأشكال المنتظمة، الأدنى = الأقصى

### علامة التبويب 5: الوصف

#### الوصف

| الخاصية | القيمة |
|---------|--------|
| **اسم الحقل** | `description` |
| **النوع** | نص متعدد الأسطر |
| **الحد الأقصى للطول** | غير محدود |

**الوصف:** وصف فيزيائي تفصيلي للقطعة الأثرية.

**ما يجب تضمينه:**
1. المظهر العام
2. اللون والسطح
3. الزخرفة/الحلي
4. النقوش أو العلامات
5. تقنية التصنيع
6. أنماط التآكل
7. وصف الضرر

**مثال:**
```
دبوس برونز، نوع القوس، كامل.
زنجار أخضر داكن مع مناطق تآكل نشط (بقع خضراء فاتحة).
مزين بنمط هندسي محزوز على القوس - ثلاثة خطوط متوازية
تتقاطع مع تهشير قطري. الدبوس سليم، لوحة الإمساك مكسورة.
آلية النابض بـ 4 لفات، نابض ثنائي الجانب.
الطول 5.8 سم، أقصى عرض عند القوس 1.2 سم.
تآكل مرئي على المشبك من الاستخدام. ترسبات بحرية على الجانب السفلي.
التصنيف النمطي: Blinkenberg Type XII.3
```

## نظام التصنيف

### تحديد المادة

#### المعادن

| المعدن | اللون (جديد) | اللون (متآكل) | مغناطيسي |
|--------|--------------|---------------|----------|
| برونز | ذهبي | أخضر | لا |
| نحاس | أحمر نحاسي | أخضر | لا |
| حديد | رمادي فضي | برتقالي/بني | نعم |
| رصاص | رمادي مزرق | أبيض | لا |
| ذهب | ذهبي | ذهبي (مستقر) | لا |
| فضة | فضي | أسود | لا |

#### المواد العضوية

| المادة | الخصائص | الحفظ |
|--------|---------|-------|
| خشب | ألياف مرئية | غالباً مشبع بالماء |
| عظم | كثيف، ناعم | متغير |
| عاج | كثيف، ناعم الحبيبات | جيد إذا مستقر |
| جلد | مرن (رطب) | نادر |
| نسيج | ألياف منسوجة | نادر جداً |

### التصنيف الوظيفي

```
الأدوات
├── أدوات القطع (سكاكين، مناشير)
├── أدوات الثقب (مخارز، مثاقب)
├── أدوات الطرق (مطارق)
└── أدوات القياس (أوزان، مقاييس)

الأغراض الشخصية
├── المجوهرات (خواتم، دبابيس، أقراط)
├── العناية الشخصية (أمشاط، مرايا، شفرات حلاقة)
├── الملابس (أزرار، إبزيمات، دبابيس)
└── الكتابة (أقلام، أختام)

تجهيزات السفينة
├── التثبيتات (مسامير، برشامات، براغي)
├── الحبال (بكرات، عيون ميتة، كشتبانات)
├── الملاحة (أثقال، بوصلات)
└── الإرساء (أجزاء المرساة، سلاسل)

الشحن
├── البضائع التجارية (سبائك، مواد خام)
├── الحاويات (أمفورات، جرار)
└── الثمينات (عملات، سبائك ذهبية)
```

## إرشادات القياس

### بروتوكول القياس المعياري

1. **الطول (L)**: أطول بُعد
2. **العرض (W)**: عمودي على الطول
3. **السماكة (T)**: عمودي على كليهما

### مخطط القياس

```
        ┌─────────────────────┐
        │                     │
   T    │         W           │  T
(سماكة) │   ←───────────→     │ (سماكة)
        │                     │
        └─────────────────────┘
                  ↑
                  │
                  L
              (طول)
```

### الحالات الخاصة

**الأجسام الدائرية:**
- القطر بدلاً من L × W
- لاحظ إذا كان القياس داخلي أو خارجي

**الأجسام غير المنتظمة:**
- سجّل الأبعاد القصوى
- استخدم حقول الأدنى/الأقصى
- صف نقاط القياس في الملاحظات

**الأجسام المجزأة:**
- قس ما هو موجود
- لاحظ الأبعاد "المحفوظة"
- قدّر الحجم الأصلي إن أمكن

## سير عمل الترميم

### التقييم الأولي

1. **حدد المادة**
   - الفحص البصري
   - اختبارات بسيطة (مغناطيس للحديد)
   - دوّن عدم اليقين

2. **قيّم الحالة**
   - الاستقرار
   - التآكل/التحلل النشط
   - الهشاشة

3. **حدد الأولوية**
   - عاجل: تدهور نشط
   - عالي: غير مستقر لكن بطيء
   - متوسط: مستقر مع مخاوف
   - منخفض: مستقر

### تسجيل الترميم

1. افتح سجل القطعة الأثرية
2. اذهب إلى علامة تبويب الترميم
3. حدّث الحقول:
   - الحالة
   - وصف المعالجة
   - التاريخ
   - اسم المرمم
4. احفظ السجل

### الربط بنموذج الترميم

لسجلات المعالجة التفصيلية:
1. افتح **HFF > ترميم القطع الأثرية**
2. اربط بسجل القطعة الأثرية عبر المعرف
3. سجّل معالجات تفصيلية
4. تتبع العينات
5. وثّق قبل/بعد

## التوثيق ثلاثي الأبعاد

### متى تستخدم 3D

| الأولوية | أنواع الأجسام |
|----------|---------------|
| عالية | أشكال معقدة، نقوش |
| متوسطة | أجسام مزخرفة، أدوات |
| منخفضة | أشكال بسيطة، قطع |

### إنشاء النماذج ثلاثية الأبعاد

**إعداد الفوتوغرامتري:**
1. سطح نظيف، مستقر
2. إضاءة منتشرة (بدون ظلال)
3. شريط مقياس في الصور
4. 50-100 صورة متداخلة
5. زوايا متعددة (من جميع الجهات)

**متطلبات الصور:**
| الإعداد | القيمة |
|---------|--------|
| التداخل | >60% |
| التنسيق | RAW أو JPEG (جودة عالية) |
| التركيز | يدوي، ثابت |
| فتحة العدسة | f/8 - f/11 |

### تحميل النماذج ثلاثية الأبعاد

1. انقر زر **عارض 3D**
2. اختر **تحميل نموذج**
3. اختر الملف (.obj، .ply، .stl)
4. يُعرض النموذج في العارض

### عناصر التحكم في العارض ثلاثي الأبعاد

| الإجراء | التحكم |
|---------|--------|
| تدوير | نقر يسار + سحب |
| تكبير | عجلة التمرير |
| تحريك | نقر يمين + سحب |
| إعادة ضبط | نقر مزدوج |

## الأخطاء الشائعة والحلول

### خطأ: "معرف القطعة الأثرية موجود بالفعل"

| السبب | الحل |
|-------|------|
| معرف مكرر | استخدم معرفاً فريداً |
| السجل موجود | ابحث أولاً |

### خطأ: "قياس غير صالح"

| السبب | الحل |
|-------|------|
| نص في حقل رقمي | أدخل أرقاماً فقط |
| قيمة سالبة | استخدم قيماً موجبة |
| تنسيق خاطئ | تحقق من النقطة العشرية |

### خطأ: "لا يمكن حفظ السجل"

| السبب | الحل |
|-------|------|
| حقل المعرف فارغ | أدخل معرف القطعة الأثرية |
| قاعدة البيانات مقفلة | انتظر وأعد المحاولة |
| فُقد الاتصال | تحقق من الاتصال |

### خطأ: "الصور لا تُعرض"

| السبب | الحل |
|-------|------|
| مسار خاطئ | تحقق من إعدادات الوسائط |
| الملفات نُقلت | أعد ربط الصور |
| مشكلة تنسيق | حوّل إلى JPEG/PNG |

### خطأ: "النموذج ثلاثي الأبعاد لا يُحمّل"

| السبب | الحل |
|-------|------|
| تنسيق غير مدعوم | حوّل إلى OBJ/PLY |
| الملف كبير جداً | قلّل حجم الشبكة |
| ملف تالف | أعد تصدير النموذج |

## أفضل الممارسات

### إدخال البيانات

1. **أكمل التعريف أولاً**
   - المعرف، الموقع، المنطقة
   - رابط سجل الغوص
   - تاريخ الاكتشاف

2. **صنّف بدقة**
   - المادة مؤكدة مقابل محتملة
   - استخدم "غير معروف" إذا غير متأكد
   - دوّن أساس التحديد

3. **قس باتساق**
   - نفس نقاط المرجع
   - نفس الوحدات (السنتيمتر معيار)
   - سجّل الطريقة

### التوثيق

1. **صوّر بشمولية**
   - جميع الجوانب
   - التفاصيل (علامات، ضرر)
   - مع مقياس
   - قبل التنظيف

2. **صف بالكامل**
   - الوصف الفيزيائي
   - ملاحظات الحالة
   - معلومات السياق

3. **استشهد بشكل صحيح**
   - اربط بسجلات الغوص
   - استشهد بالمقارنات
   - ضمّن المراجع

### الترميم

1. **قيّم فوراً**
   - دوّن الحالة عند الاكتشاف
   - حدد الاحتياجات العاجلة
   - خطط المعالجة

2. **تتبع المعالجات**
   - سجّل جميع التدخلات
   - دوّن المنتجات المستخدمة
   - وثّق النتائج

3. **راقب التخزين**
   - تحقق دورياً
   - دوّن أي تغييرات
   - حدّث السجلات
