## المقدمة

الإعداد الصحيح لقاعدة البيانات ضروري لاستخدام HFF بفعالية. يغطي هذا الدليل جميع جوانب إعداد قاعدة البيانات، من إعدادات SQLite البسيطة لمستخدم واحد إلى عمليات نشر PostgreSQL للمؤسسات.

<!-- VIDEO: Database configuration overview -->
> **فيديو تعليمي**: الدليل الكامل لإعداد قاعدة بيانات HFF

### مقارنة قواعد البيانات

| الميزة | SQLite/SpatiaLite | PostgreSQL/PostGIS |
|--------|-------------------|-------------------|
| **تعقيد الإعداد** | بسيط | متوسط |
| **خادم مطلوب** | لا | نعم |
| **تعدد المستخدمين** | محدود | دعم كامل |
| **الوصول عبر الشبكة** | مشاركة ملفات فقط | أصلي |
| **الأداء** | جيد لمجموعات البيانات الصغيرة | أفضل لمجموعات البيانات الكبيرة |
| **النسخ الاحتياطي** | نسخ الملف | pg_dump/pg_restore |
| **الأفضل لـ** | مستخدمين فرديين، العمل الميداني | الفرق، المؤسسات |

| الوظيفة | الغرض |
|---------|-------|

| `ST_Within(g1, g2)` | اختبار الاحتواء المكاني |
| `ST_Buffer(geom, dist)` | إنشاء منطقة عازلة |

## إعداد PostgreSQL/PostGIS

### نظرة عامة

PostgreSQL مع PostGIS موصى بها لـ:
- مشاريع الفرق
- مجموعات البيانات الكبيرة (>10,000 سجل)
- متطلبات الوصول عبر الشبكة
- عمليات نشر المؤسسات
- التحرير المتزامن

<!-- IMAGE: PostgreSQL configuration -->
![إعداد PostgreSQL](images/02_configuration/07_postgresql_config.png)
*الشكل 7: لوحة إعداد PostgreSQL*

### المتطلبات المسبقة

قبل إعداد PostgreSQL في HFF:

| المتطلب | الوصف | كيفية التحقق |
|---------|-------|--------------|
| **خادم PostgreSQL** | الإصدار 12 أو أعلى | `psql --version` |
| **امتداد PostGIS** | الإصدار 3.0 أو أعلى | `SELECT PostGIS_Version();` |
| **قاعدة البيانات مُنشأة** | قاعدة بيانات فارغة لـ HFF | pgAdmin أو `createdb` |
| **حساب مستخدم** | مستخدم بصلاحيات الإنشاء | pgAdmin أو `\du` |
| **الوصول للشبكة** | المنفذ 5432 مفتوح | `telnet host 5432` |

### معلمات الاتصال

| المعلمة | الوصف | مثال |
|---------|-------|------|
| **المضيف** | اسم مضيف الخادم أو IP | `localhost` أو `192.168.1.100` |
| **المنفذ** | منفذ PostgreSQL | `5432` (افتراضي) |
| **قاعدة البيانات** | اسم قاعدة البيانات | `hff_survey` |
| **اسم المستخدم** | مستخدم قاعدة البيانات | `hff_user` |
| **كلمة المرور** | كلمة مرور المستخدم | `********` |
| **المخطط** | مخطط قاعدة البيانات | `public` (افتراضي) |

### الإعداد خطوة بخطوة

#### الخطوة 1: إعداد خادم PostgreSQL

على خادم قاعدة البيانات، أنشئ قاعدة البيانات والمستخدم:

```sql
-- إنشاء مستخدم
CREATE USER hff_user WITH PASSWORD 'your_password';

-- إنشاء قاعدة بيانات
CREATE DATABASE hff_survey OWNER hff_user;

-- الاتصال بقاعدة البيانات
\c hff_survey

-- تفعيل PostGIS
CREATE EXTENSION postgis;

-- منح الصلاحيات
GRANT ALL PRIVILEGES ON DATABASE hff_survey TO hff_user;
```

#### الخطوة 2: إعداد HFF
1. افتح نافذة الإعدادات
2. اختر **PostgreSQL** من نوع قاعدة البيانات

## إعداد متعدد المستخدمين

### إدارة مستخدمي PostgreSQL

لعمليات نشر الفرق مع PostgreSQL:

<!-- IMAGE: User management -->
![إدارة المستخدمين](images/02_configuration/18_user_management.png)
*الشكل 18: لوحة إدارة المستخدمين*

### إنشاء المستخدمين

#### في PostgreSQL:
```sql
-- إنشاء مستخدم للقراءة فقط
CREATE USER viewer WITH PASSWORD 'password';
GRANT SELECT ON ALL TABLES IN SCHEMA public TO viewer;

-- إنشاء مستخدم محرر
CREATE USER editor WITH PASSWORD 'password';
GRANT SELECT, INSERT, UPDATE ON ALL TABLES IN SCHEMA public TO editor;

-- إنشاء مستخدم مسؤول
CREATE USER admin WITH PASSWORD 'password';
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO admin;
```

#### في مدير مستخدمي HFF:
1. القائمة **HFF Survey** ← **إدارة المستخدمين**
2. انقر **إضافة مستخدم**
3. أدخل اسم المستخدم وكلمة المرور
4. اختر الدور
5. انقر **حفظ**

### صلاحيات الأدوار

| الدور | الصلاحيات |
|-------|----------|
| **مشاهد** | قراءة فقط، بحث، تصدير |
| **محرر** | عرض + إنشاء وتعديل السجلات |
| **مسؤول** | وصول كامل بما فيه الحذف |
| **مسؤول أعلى** | وصول كامل + إدارة المستخدمين |

### التحرير المتزامن

PostgreSQL يتعامل مع التحرير المتزامن:

| السيناريو | السلوك |
|-----------|--------|
| **نفس السجل مُحرَّر** | آخر حفظ يفوز |
| **السجل مقفل** | يُعرض إشعار |
| **تم اكتشاف تعارض** | المستخدم يختار الإصدار |

## النسخ الاحتياطي والاستعادة

### النسخ الاحتياطي لـ SQLite

#### النسخ الاحتياطي اليدوي
1. أغلق HFF (موصى به)
2. انسخ ملف `.sqlite` إلى موقع النسخ الاحتياطي
3. تحقق من أن حجم النسخة يطابق الأصل

#### النسخ الاحتياطي المجدول (macOS/Linux)
```bash
# أضف إلى crontab للنسخ الاحتياطي اليومي
0 2 * * * cp ~/HFF/HFF_DB_folder/hff.sqlite ~/backups/hff_$(date +%Y%m%d).sqlite
```

#### النسخ الاحتياطي المجدول (Windows)
أنشئ مهمة مجدولة لتشغيل:
```batch
copy "%USERPROFILE%\HFF\HFF_DB_folder\hff.sqlite" "%USERPROFILE%\backups\hff_%date:~-4,4%%date:~-10,2%%date:~-7,2%.sqlite"
```

### النسخ الاحتياطي لـ PostgreSQL

#### باستخدام pg_dump
```bash
# نسخ احتياطي كامل لقاعدة البيانات
pg_dump -h localhost -U hff_user -d hff_survey > backup.sql

# نسخ احتياطي مضغوط
pg_dump -h localhost -U hff_user -d hff_survey | gzip > backup.sql.gz

# صيغة مخصصة (استعادة أسرع)
pg_dump -h localhost -U hff_user -Fc hff_survey > backup.dump
```

#### النسخ الاحتياطي المجدول
```bash
# نسخ احتياطي يومي مع تدوير
pg_dump -h localhost -U hff_user -Fc hff_survey > /backups/hff_$(date +%Y%m%d).dump
find /backups -name "hff_*.dump" -mtime +30 -delete
```

### إجراءات الاستعادة

#### استعادة SQLite
1. أغلق HFF
2. استبدل ملف قاعدة البيانات بالنسخة الاحتياطية
3. أعد تشغيل HFF

#### استعادة PostgreSQL
```bash
# من ملف SQL
psql -h localhost -U hff_user -d hff_survey < backup.sql

# من صيغة مخصصة
pg_restore -h localhost -U hff_user -d hff_survey backup.dump
```

## حل المشاكل

### مشاكل الاتصال

#### خطأ "الاتصال مرفوض"

**السبب**: PostgreSQL لا يعمل أو المنفذ محجوب

**الحلول**:
1. تحقق من خدمة PostgreSQL:
   ```bash
   sudo service postgresql status  # Linux
   brew services list              # macOS
   ```
2. تحقق من أن المنفذ مفتوح:
   ```bash
   telnet localhost 5432
   ```
3. تحقق من pg_hba.conf لوصول العميل

#### خطأ "فشل المصادقة"

**السبب**: اسم مستخدم أو كلمة مرور خاطئة

**الحلول**:
1. تحقق من البيانات في pgAdmin
2. تحقق من عدم انتهاء صلاحية كلمة المرور
3. جرب الاتصال عبر psql:
   ```bash
   psql -h localhost -U hff_user -d hff_survey
   ```

#### خطأ "قاعدة البيانات غير موجودة"

**السبب**: قاعدة البيانات لم تُنشأ

**الحلول**:
1. أنشئ قاعدة البيانات:
   ```sql
   CREATE DATABASE hff_survey;
   ```
2. تحقق من قائمة قواعد البيانات:
   ```bash
   psql -l
   ```

### مشاكل SQLite

#### خطأ "قاعدة البيانات مقفلة"

**السبب**: عمليات متعددة تصل للملف

**الحلول**:
1. أغلق التطبيقات الأخرى التي تستخدم الملف
2. تحقق من عمليات QGIS الميتة
3. فعّل وضع WAL:
   ```sql
   PRAGMA journal_mode=WAL;
   ```

#### خطأ "صورة قرص قاعدة البيانات تالفة"

**السبب**: تلف، ربما من إيقاف غير صحيح

**الحلول**:
1. جرب فحص السلامة:
   ```sql
   PRAGMA integrity_check;
   ```
2. استعد من نسخة احتياطية
3. استخدم sqlite3 لتفريغ وإعادة إنشاء:
   ```bash
   sqlite3 corrupt.db ".dump" | sqlite3 new.db
   ```

### مشاكل الجداول

#### خطأ "الجدول غير موجود"

**السبب**: الجداول لم تُنشأ بشكل صحيح

**الحلول**:
1. انقر **إنشاء الجداول** في الإعدادات
2. تحقق يدوياً من وجود الجداول
3. تحقق من أذونات قاعدة البيانات

#### خطأ "العمود غير موجود"

**السبب**: عدم تطابق إصدار المخطط

**الحلول**:
1. شغّل ترحيل قاعدة البيانات
2. تحقق من تحديثات المخطط
3. قارن قائمة الأعمدة مع المخطط المتوقع
