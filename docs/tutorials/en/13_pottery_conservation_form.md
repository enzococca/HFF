# Pottery Conservation Form - Complete Tutorial

The Pottery Conservation Form documents conservation treatments and analysis of ceramic artifacts in the HFF Survey system.

## Opening the Pottery Conservation Form

1. Click the **Pottery Conservation** icon in the HFF toolbar
2. Or navigate to **HFF Menu > Pottery Conservation Form**

## Form Sections

### Identification Section

| Field | Description |
|-------|-------------|
| **ID** | Unique conservation record identifier |
| **Pottery ID** | Reference to the original pottery record |
| **Site** | Archaeological site name |
| **Date** | Conservation treatment date |
| **Conservator** | Name of conservator performing treatment |

### Condition Assessment

#### Pre-Treatment Condition

| Field | Description |
|-------|-------------|
| **Overall Condition** | General state (Good, Fair, Poor, Fragmentary) |
| **Completeness** | Percentage complete (%) |
| **Number of Fragments** | Count of fragments |
| **Surface Condition** | State of surface (Stable, Friable, Flaking) |
| **Structural Integrity** | Strength assessment |

#### Damage Types

Document all damage present:

- **Mechanical Damage**: Cracks, chips, breaks
- **Surface Loss**: Slip loss, glaze deterioration
- **Deposits**: Salt efflorescence, concretions
- **Staining**: Discoloration, organic stains
- **Previous Repairs**: Old adhesives, fills

### Analysis Section

| Field | Description |
|-------|-------------|
| **Fabric Analysis** | Paste composition description |
| **Temper Type** | Inclusions identified |
| **Firing Temperature** | Estimated firing temp |
| **Hardness** | Mohs scale rating |
| **Color** | Munsell color notation |

### Treatment Documentation

#### Cleaning Methods

| Method | Description |
|--------|-------------|
| **Dry Cleaning** | Brushing, air abrasion |
| **Wet Cleaning** | Water, solvents used |
| **Poultice** | Materials and duration |
| **Mechanical** | Scalpel, tools used |

#### Consolidation

| Field | Description |
|-------|-------------|
| **Consolidant** | Material used (e.g., Paraloid B-72) |
| **Concentration** | Percentage in solvent |
| **Application Method** | Brush, injection, immersion |
| **Number of Applications** | Coats applied |

#### Joining and Fills

| Field | Description |
|-------|-------------|
| **Adhesive** | Type used for joining |
| **Fill Material** | Plaster, epoxy, etc. |
| **Retouching** | Color matching technique |

### Storage and Recommendations

| Field | Description |
|-------|-------------|
| **Storage Location** | Where artifact is stored |
| **Storage Conditions** | Temperature, humidity requirements |
| **Handling Notes** | Special precautions |
| **Future Treatment** | Recommended follow-up |

## Workflow: Complete Conservation Record

### Step 1: Initial Documentation

1. Click **New Record**
2. Enter pottery reference ID
3. Document pre-treatment condition
4. Take photographs

### Step 2: Analysis

1. Perform fabric analysis
2. Document physical properties
3. Note any special characteristics

### Step 3: Treatment

1. Document each treatment step
2. Record materials used
3. Note concentrations and methods
4. Take in-progress photos

### Step 4: Post-Treatment

1. Document final condition
2. Compare to pre-treatment
3. Add storage recommendations
4. Click **Save**

---

## Linking to Pottery Records

Conservation records can be linked to pottery records:

1. Enter the **Pottery ID** field
2. Use the lookup button to search
3. Select the correct pottery record
4. Link is established

---

## Conservation Report PDF

Generate professional reports:

1. Navigate to desired record
2. Click **Export PDF**
3. Report includes:
   - Condition assessment
   - Treatment details
   - Before/after photos
   - Recommendations

## Best Practices

### Documentation

- Photograph before, during, and after treatment
- Use standardized terminology
- Record all materials with batch numbers
- Include measurements

### Data Entry

- Complete all relevant fields
- Be specific about methods
- Note any unusual observations
- Link to related records
