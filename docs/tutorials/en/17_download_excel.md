# Excel Export

This tutorial explains how to export your HFF Survey data to Microsoft Excel format for analysis, reporting, and data sharing.

## Overview

HFF provides comprehensive Excel export capabilities:

- Single record export
- Filtered data export
- Full database export
- Custom field selection
- Formatted tables with headers

---

## Export Methods

### From Any Form

Every HFF form includes Excel export:

1. Open the desired form (Site, Artefact, etc.)
2. Click the **Excel Export** button ![Excel](icons/excel-export.png)
3. Choose export options
4. Save the file

### Quick Export (Current View)

1. Click **Export Excel** button
2. Exports currently displayed records
3. Includes all visible fields

### Filtered Export

1. Apply search/filter first
2. Click **Export Excel**
3. Only filtered records are exported

---

## Export Options

### Record Selection

| Option | Description |
|--------|-------------|
| **Current Record** | Export only the displayed record |
| **Filtered Records** | Export records matching current filter |
| **All Records** | Export entire table |
| **Selected Records** | Export manually selected items |

### Field Selection

Choose which fields to include:

1. Click **Field Selection** before export
2. Check/uncheck fields
3. Reorder fields by dragging
4. Save selection as preset

### Format Options

| Option | Description |
|--------|-------------|
| **Include Headers** | Add column names as first row |
| **Format Dates** | Standard date format |
| **Format Numbers** | Decimal places, thousands separator |
| **Include Empty Fields** | Show fields with no data |

---

## Step-by-Step: Basic Export

### Step 1: Navigate to Form

1. Open HFF form with your data
2. Or filter to desired records

### Step 2: Start Export

1. Click **Excel Export** button
2. Export dialog opens

### Step 3: Configure Export

1. Select records to export
2. Choose fields (or keep all)
3. Set format options

### Step 4: Save File

1. Click **Export**
2. Choose save location
3. Enter filename
4. Click **Save**

### Step 5: Open in Excel

1. Navigate to saved file
2. Open with Excel or compatible app
3. Data is ready for use

## Export Formats

### Standard Excel (.xlsx)

- Modern Excel format
- Supports large datasets
- Formatting preserved
- Recommended for most uses

### CSV Export

For maximum compatibility:

1. Export as Excel first
2. Save As > CSV format
3. Or use CSV export option

### Multiple Sheets

Complex exports can include:

- Main data sheet
- Related records sheet
- Lookup values
- Metadata

## Data Analysis Tips

### Pivot Tables

After export:

1. Select data range
2. Insert > Pivot Table
3. Analyze by:
   - Site type counts
   - Material distributions
   - Chronological patterns

### Charts

Create visualizations:

1. Select data columns
2. Insert > Chart
3. Choose chart type
4. Customize appearance

### Filtering

Use Excel filters:

1. Click any header cell
2. Data > Filter
3. Click dropdown arrows
4. Filter by value

## Batch Export

### Export Multiple Forms

1. Open **Export Manager**
2. Select forms to export:
   - Sites
   - Artefacts
   - Pottery
   - etc.
3. Choose output folder
4. Click **Export All**
5. Separate file for each form

### Scheduled Export

For regular backups:

1. Configure export settings
2. Save as export profile
3. Run manually or schedule

## Troubleshooting

### Export Fails

- Check disk space
- Verify write permissions
- Try different location
- Reduce record count

### Missing Data

- Check field selection
- Verify filter settings
- Ensure records exist

### Formatting Issues

- Check regional settings
- Verify date formats
- Try CSV format

### Large Files

- Split by date range
- Export in batches
- Use CSV for very large datasets

## Best Practices

1. **Regular Exports**: Create backups regularly
2. **Naming Convention**: Include date in filename
3. **Field Documentation**: Keep field descriptions
4. **Version Control**: Track export versions
5. **Validation**: Spot-check exported data
