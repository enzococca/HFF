about=HFF (Honor Frost Foundation) is a comprehensive open-source plugin for archaeological survey data management within QGIS.
    It provides tools for managing underwater and terrestrial survey data, including:
    - Dive log management and recording
    - Anchor, shipwreck, and artefact cataloging
    - Pottery analysis and inventory
    - EAMENA heritage site documentation
    - PDF report generation
    - Image and media management with tagging
    - PostgreSQL/PostGIS and SQLite/Spatialite database support
    - GIS integration for spatial analysis

    Developed with support from the Honor Frost Foundation.
    Documentation: https://github.com/enzococca/HFF
    GitHub: https://github.com/enzococca/HFF
